# Madhu Portfolio — Agent Rules

This is a personal portfolio project built with TanStack Start, React, TypeScript, and Tailwind CSS.

## Stack
- **Framework**: TanStack Start (SSR)
- **Routing**: TanStack Router (file-based)
- **Styling**: Tailwind CSS v4
- **UI**: shadcn/ui components (Radix UI primitives)
- **Package manager**: npm / bun

## Development
```sh
npm i
npm run dev
```

## Notes
- Do not edit auto-generated files (e.g. `src/routeTree.gen.ts`).
- Do not put secret values in the repo.
