# Madhu Portfolio

A premium modern portfolio website with a warm split-screen hero layout, built with TanStack Start, React, TypeScript, and Tailwind CSS.

## Stack

- [TanStack Start](https://tanstack.com/start) — full-stack SSR framework
- [TanStack Router](https://tanstack.com/router) — type-safe file-based routing
- [Tailwind CSS v4](https://tailwindcss.com)
- [shadcn/ui](https://ui.shadcn.com) — Radix UI-based component library
- [Vite](https://vite.dev)

## Development

Requires [Node.js](https://nodejs.org/) (v20+).

```sh
git clone <this-repository-url>
cd Madhu-portflio
npm i
npm run dev
```

## Available Scripts

| Script | Description |
|---|---|
| `npm run dev` | Start the dev server |
| `npm run build` | Production build |
| `npm run preview` | Preview the production build |
| `npm run lint` | Run ESLint |
| `npm run format` | Run Prettier |
| `npm test` | Run unit tests |
