# Warm Split Portfolio

Create a premium modern portfolio website hero section with a split-screen layout.

The hero should occupy the full viewport height (100vh).

Left Side (55%)

- Warm orange gradient background (#FF6A00 to #2D0F05).

- Large bold heading occupying most of the space.

- Small description below.

- Rounded CTA button.

- Client avatars section near the bottom.

- Soft abstract circular background shapes.

- Lots of breathing space.

Right Side (45%)

- Clean white background.

- Top navigation aligned horizontally.

- Circular menu button on the top-right.

- Availability text.

- Small testimonial card at the bottom-right.

The overall layout should feel luxurious, minimal, modern, and suitable for a UI/UX designer portfolio.
